# רווחה נפשית — V4

## תפקיד המוצר
כלי אישי, פרטי ולא רפואי שמסייע להוריד עומס ולבחור צעד קטן. הוא אינו מאבחן, מטפל או מחליף עזרה אנושית מקצועית.

## הזרימה היומית
1. לבחור עומס: קל, עמוס או כבד — או לא לבחור כלל.
2. לבחור צעד קטן, או לשחרר את היום.
3. בעומס כבד לבחור פעולה אחת להקלה: להקטין התחייבות, לדחות החלטה או לבקש עזרה.
4. אם בוחרים לבקש עזרה, עוברים לרשת התמיכה בלבד; שום הודעה לא נשלחת אוטומטית.

## אוטומציה
- אין התראות אוטומטיות, רצפים, ציונים או פנייה יזומה לאנשי תמיכה.
- תזכורת עתידית תהיה opt-in בלבד, עם זמן/ימים לבחירת המשתמש וכיבוי מיידי.
- פרטי אנשי תמיכה והטקסטים אינם מועברים להנהלה. סיכום הנהלה, אם יופעל בעתיד, יהיה רק סטטוס מפורש ולא טקסט אישי.

## בדיקות קבלה
- שימוש מלא במסך 320–430px.
- חזרה, רענון ושינוי טאב לא מאבדים פעולה שנשמרה.
- כל שמירה/מחיקה מציגה משוב ברור.
- מחיקה דורשת אישור.
- לחצן ביטול בטופס תמיכה אינו שומר בטעות.
