# שילוב חברת הקריירה

החברה "קריירה" נמצאת בנתיב `/companies/avoda` בתוך Personal HQ. זהו סבב ראשון של
העברת יכולות מ־Job-guide; אין בו העתקת היסטוריית Git, נתוני משתמשים, מפתחות API או קבצים אישיים.

## מה זמין

- הוספה, עריכה ומחיקה מאושרת של מועמדויות.
- חברה, תפקיד, קישור HTTPS ציבורי, סטטוס, תאריך הגשה, צעד הבא, מועד, הערות ותיאור משרה.
- חיפוש לפי חברה או תפקיד, סינון סטטוס ועימוד של 10 פריטים.
- סיכום למנכ"ל: מועמדויות פעילות, ראיונות, צעדים באיחור והצעד הבא.
- שמירה מיידית של מועמדות ללא קריאת AI או הורדת קישור. השמירה מאמתת משתמש, בודקת שינוי מקביל ומציגה כשל במקום להציג הצלחה שגויה.

## מה טרם הועבר

- ייבוא נתונים מ־Job-guide.
- קורות חיים, תרגול שאלות, סימולציות ראיון ומשוב AI.
- ניתוח אוטומטי של קישור משרה. קישורים נשמרים בלבד עד שתוגדר שכבת שרת עם רשימת יעדים, בדיקת הפניות ומגבלות גודל.

המערכת הקיימת ב־`pm-interview-prep-ivory.vercel.app` נשארת פעילה כרשת ביטחון לאורך ההעברה.

## בדיקה ידנית

1. התחברו ל־Personal HQ ובחרו "קריירה" ממסך המנכ"ל.
2. הוסיפו מועמדות עם שם חברה ותפקיד, שמרו ורעננו את הדף.
3. ערכו את הסטטוס והצעד הבא, ובדקו שהסיכום במסך המנכ"ל משתנה.
4. נסו למחוק מועמדות ובחרו "ביטול" לפני אישור כדי לוודא שהיא נשארת.
5. נסו קישור שאינו HTTPS או קישור ל־localhost; הטופס צריך לסרב לו.

## בדיקות אוטומטיות

`npm test` בודק תקינות נתוני מועמדות, סינון ועימוד, וחסימת קישורים לא בטוחים.

`npm run build` מאמת את בניית Next.js. בסביבה ללא משתני Supabase יש להגדיר ערכי בדיקה לא־סודיים לבנייה בלבד.
